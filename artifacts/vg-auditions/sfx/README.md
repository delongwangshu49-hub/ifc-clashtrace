# VG SFX auditions

Original deterministic synthesis; VG audition only, not final G7A sound design. P1 is selected; the WAV auditions remain local-only and are excluded from the public VG checkpoint.

Each 6.2-second file presents: UI click → transition whoosh → result impact → settle tone.

- P1 Dry Precision: recommended; shortest and least decorative.
- P2 Soft Glass: brighter and more tonal.
- P3 Cinematic Air: widest and most cinematic.

Generated by `scripts/generate-vg-sfx-auditions.py` at 48 kHz stereo.
